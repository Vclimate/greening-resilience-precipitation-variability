# ERA5 解释因子统一重算

脚本：`ERA5_all_covariates_bilinear_005_GEE.js`。这是独立的 GEE Code Editor JavaScript，不依赖旧脚本，也不覆盖旧数据。

## 运行与输出

在 [GEE Code Editor](https://code.earthengine.google.com/) 中运行脚本。月份完整性检查和10项数值自检通过后，会生成导出任务；需在 Tasks 中分别点击 Run。脚本不自动启动任务。

- 数据源：`ECMWF/ERA5_LAND/MONTHLY_AGGR`。
- 默认一般指标：2000–2023年；P.SI、P.NIPV：1990–2023年。保留本轮旧数据核查使用的时段，**没有自动延长至2024年**。如需调整，在脚本顶部修改 `studyEnd` 等设置，并同步修改方法表述。
- 默认输出14项：10个解释因子 GeoTIFF、2个质量检查 GeoTIFF、1个元数据 CSV、1个原始网格月值核查 CSV。
- Google Drive 文件夹：`JRS_ERA5_all_bilinear_005_recomputed`。
- 本地仅完成语法和部分公式检查，**尚未在已授权的 GEE 会话中执行或提交导出**。

## 指标定义

| 指标 | 计算方式 | 输出单位 |
|---|---|---|
| P | 月累计降水转为mm，逐年求和，再取多年均值 | mm yr⁻¹ |
| dP | 对逐年降水总量作OLS线性回归，取斜率 | mm yr⁻² |
| P.SI | 每年SI = Σₘ \|Pₘ − P年/12\| / P年，再取多年均值 | 1 |
| P.NIPV | 年降水总量的样本标准差 / 多年均值；不去趋势 | 1 |
| Ta | 月平均气温转为°C，先年均，再多年均值 | °C |
| dTa | 对逐年平均气温作OLS线性回归，取斜率 | °C yr⁻¹ |
| VPD | 按指定MATLAB公式用月平均气温和露点温度计算，再年均和多年均值 | hPa |
| SM | 土壤水分两层按厚度加权：(7×SWVL1 + 21×SWVL2)/28，即0–28 cm | m³ m⁻³ |
| Rs | 月累计短波辐射除以当月天数，再对12个月及各年取均值 | J m⁻² day⁻¹ |
| P−ET | ET = −原始月累计蒸发量×1000；逐年求和P−ET，再取多年均值 | mm yr⁻¹ |

Ta、VPD、SM、Rs采用12个月等权均值，与核查到的旧代码一致，不是按月天数加权。Rs换成MJ m⁻² day⁻¹时除以10⁶；它不是年累计辐射，也不是W m⁻²。

GEE产品的降水、蒸发和辐射 `_sum` 波段已经是月累计量，**降水和蒸发不能再次乘以月天数**。这与旧CDS月平均累计变量的处理不同。参见[数据集说明](https://developers.google.com/earth-engine/datasets/catalog/ECMWF_ERA5_LAND_MONTHLY_AGGR)。

### VPD公式

依据：`D:\Code_Model\19636059\ForestResilience\VPD\cal_VPD\cal_VPD.m`。

`VPD = 6.112 exp[aT/(T+b)] − 6.112 exp[aTd/(Td+b)]`，T和Td均为°C。

- 气温T ≥ 0°C：a = 17.67，b = 243.5。
- 气温T < 0°C：a = 22.46，b = 272.62。
- **两项均由气温T选择参数**，不单独按露点温度切换相态，保持指定代码的规则。
- 此处是“用月平均温度计算的VPD”，不等同于“逐小时VPD的月平均值”；方法中需按实际定义表述。

### 降水变率

P.SI是逐年SI的多年平均，不是先计算12个月多年气候态后再求一次SI。P.NIPV使用样本标准差（分母N−1）。两项均要求基准期每年月份完整，但有效值规则不同：P.SI要求每年降水总量为正；P.NIPV允许某一年降水总量为0，只要求整个时段的多年均值大于0。

## 网格与有效值规则

- 先在数据集原始网格计算全部指标，再将连续结果**双线性插值**至0.05°。这不是重新获得0.05°的原始气候信息，也不保证与旧MATLAB散点 `griddata(...,'linear')` 完全一致。
- 采用数据集自带坐标，不重建旧代码中的经度数组。
- EPSG:4326；变换参数 `[0.05, 0, -180, 0, -0.05, 80]`；覆盖约80°N–60°S，预期尺寸2800×7200。下载后必须核对实际尺寸与像元中心。
- 质量检查中的计数及离散有效标记用最近邻，不把月份数、年份数插值成小数。
- 负降水、负VPD、负辐射以及任一土层水分不在0–1范围内的月份设为无效并计数；这是显式质量控制，不能将其表述成与旧 `nanmean/nansum` 筛选完全相同。
- 蒸发保留符号：负ET代表净凝结，不直接作为无效值删除。P−ET为负也可以是有效结果。
- 各指标分别要求每年12个有效月，且整个所选时段年份完整；不以部分月份或部分年份计算完整时段指标。
- NoData为−9999，**在插值完成后**填充，避免填充值混入邻近像元。

重采样依据：[GEE重采样说明](https://developers.google.com/earth-engine/guides/resample)；导出设置依据：[Export.image.toDrive](https://developers.google.com/earth-engine/apidocs/export-image-todrive)。

## 下载后的核查

1. 检查10个指标的坐标、尺寸、单位、有效范围以及与正文像元的对应关系，再替换RF输入。
2. 查看 `QA_study` 中各变量完整年份数、异常月份数和 `all_10_predictors_valid`；查看 `QA_baseline` 中完整月份数、年份数及降水均值和标准差。
3. **双线性插值后的P.NIPV不要求等于“插值后标准差 / 插值后均值”**，因为先求比值再插值与先插值再求比值并不等价。不能沿用此前最近邻版本的这一逐像元等式作为验收条件。
4. 六个固定点的CSV保留原始网格月值与实际采样坐标，便于核查旧数据在2022–2023年的差异；若某点某月任一输出变量无效，`sampleRegions`会省略该行。
5. 月度数据完整不代表所有极端值都已证明可靠。先比较新旧空间分布和样本量，再决定是否重跑模型，不预设变量重要性会恢复旧排序。
